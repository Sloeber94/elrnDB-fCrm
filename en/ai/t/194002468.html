K020 FUEL LEVEL GAUGE NOT WORKING

Applies to: all engines; all production periods

With the ignition ON, the fuel level gauge in the instrument panel does not work (level indicated is not actual tank level);

Applies to: all engines; all production periods

The fuel level message is supplied by the "body computer node" and is made available to the "instrument panel node" via the B-CAN.The "Body Computer node" also sends the fuel level sensor error message

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner equipment to the diagnostic socket.

Check that there are no faults in the Body Computer

Move on to Step 2

Sensor with broken circuit, sensor short circuited, value implausible/not consistent with actual fuel level

Continue as described by the diagnostic equipment

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Keeping the Examiner equipment connected to the diagnostic socket, check the operation of the display in active diagnosis.

Move on to Step 3

Pointer does not move

Replace instrument panel

Op. 5560B10 CONTROL PANEL - R+R

3

CHECK FUEL LEVEL SENSOR

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check fuel level sensor operation by carrying out

See Test 1040AC FUEL LEVEL GAUGE CHECK

Move on to Step 4

Sensor not working

Replace the fuel pump assembly

Op. 1040A70 SUBMERGED PUMP ASSEMBLY COMPLETE WITH LEVEL GAUGE CONTROL - R + R

4

ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the continuity/insulation of the lead between fuel level sensor and Body Computer

See E4010 INSTRUMENT PANEL

Move on to Step 5

Cables broken/not insulated

Restore the continuity/insulation of the cable.

5

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

End of diagnosis

The fault persists

Replace Body Computer

Op. 5505A35 MAIN BODY COMPUTER/JUNCTION UNIT - R.R.
