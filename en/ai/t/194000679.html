Some nodes on the CAN network, including boot compartment M063 are programmed with default settings that the Customer will find upon purchasing the car. If boot node M063 is replaced, the Parts dept will send a blank component: once fitted, the data memorized in the body computer must be transferred to it by carrying out the "PROXY ALIGNMENT" procedure using the Examiner.

Whenever the control unit (NVB) is refitted initialise the windows and the antipinch device. The initialization of the anti-pinch safety system ensures the control unit (NVB) stores the window position parameters along the entire travel.

- Check that the control unit is not damaged.

- Position the control unit on the vehicle and secure it using the two nuts.

- Connect the two electrical connections for the control unit.

Description

Connector

LUGGAGE COMPARTMENT CONTROL UNIT (NVB)

See M063 LUGGAGE COMPARTMENT CONTROL UNIT (NVB)

To initialize the anti-crush safety system, proceed as follows:

- place the window in position at the lower end of travel position (manually or automatically);

- move the window in manual mode (without interruptions) to the upper end of its travel using the UP key.Once in this position, keep the UP control operated for at least 1 second.

After having initialized the system, the control unit (NVB) will allow both the automatic upwards movement of the window and the central opening/closing.
