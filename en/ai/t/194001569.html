Applies to: all engines; all production periods

A road map navigation system reveals the vehicle's position on a map (showing town streets and main roads/motorways) at every moment and pinpoints it on the Connect Nav+ display.

In this way the driver is guided to the required destination step by step by means of voice messages and visual information. The system also provides additional information for reaching general services, namely: hotels, carparks, restaurants, chemists, service stations, hospitals, FIAT service outlets, railway stations, airports etc.

The navigation system uses GPS (Global Positioning System) satellite localisation technology and is fitted, when ordered, in the integrated radio-phone-navigation system known as CONNECT NAV+

The navigation CD-ROM drive is located in the unit.

the navigation system only works with the CD-ROM inserted in the special drive; it is therefore possible to listen to a music CD during navigation. In this case, the navigation function requires the map CD to be inserted whilst carrying out the route calculation procedures.

As an option, it is also possible to combine the navigation system with a music audio system by fitting a CD-CHANGER in the glove compartment.

The GPS consists of an aerial that allows the vehicle to be GPS satellite-located: The aerial is connected to a receiver located in the integrated unit by means of a special shielded cable. the aerial mount and rod is fitted on the rear of the roof. It includes three cables (triple function aerial): one for the radio function, one for the phone function (GSM) and one for the navigation system (GPS).

The position of the vehicle is identified through the analysis of the GPS data and the speedometer and reverse gear signals which come from the vehicle nodes.

This position is shown by the display together with the topographical features of the area memorized in the map CD.

The navigation system also generates a voice synthesis signal that allows the driver to hear driving instructions through an audio circuit.

The radio-phone-navigation unti is a node of the CAN network via which information is exchanged with the Body Computer and the other electronic units (e.g. the navigation system downloads information from the odometer, reverse engagement signal etc.)
