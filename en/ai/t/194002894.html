The diagnostic equipment signals: Error P0685 (main relay), with detail "unexpected intervention"

Applies to: engines: 1.9 JTD 8v, 1.9 JTD 16v, 2.4 JTD 20v; all production periods

This error is detected if the main relay switches off too quickly. If the main relay switches off too quickly during a period of inactivity for the control unit, the fault codes will not be memorized.

Applies to: engines: 1.9 JTD 8v, 1.9 JTD 16v, 2.4 JTD 20v; all production periods

0

Preliminary checks

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Select the following system on the diagnostic equipment: EDC16C39 Diesel electronic injection system. Delete the errors present and turn the ignition key OFF. Wait until the engine management control unit switches off (min. 20 seconds.). Note: The main relay is switched off. If the engine is very hot, the fans remain on after the ignition is switched off. In this case, the control unit switches off automatically 10 secs after the fans are switched off.

Move on to Step 1

1

Check on operation of main relay

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Errors check. Drive the vehicle in different driving conditions (engine speed and engine load) for a long stretch. Listen out for unusual noises and other system irregularities. At the end of the road test, check that none of the following errors is present using the diagnostic equipment:

  • P0335 - Engine rpm sensor, with detail "signal not valid"
  • P0606 - Control unit broken (microprocessor)
  • P1618 – Control unit broken (HW CY940)
