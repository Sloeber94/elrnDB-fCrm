J021 HEATED REAR WINDSCREEN NOT WORKING

Applies to: all engines; all production periods

With the ignition ON, when the button in the climate control system control panel is pressed, the heated rear windscreen does not heat up properly

Applies to: all engines; all production periods

If the battery voltage is below 11.6 V, the heated rear windscreen and the rear view mirrors do not receive a power supply from the control unit.

Applies to: all engines; all production periods

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that when the button in the climate control system control panel is pressed, the rear view mirrors heat up properly

ACTION
