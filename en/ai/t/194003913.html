1060GP CHECK ENGINE CONTROL UNIT CONNECTIONS

Applies to: engines: 1.9 JTD 8v, 1.9 JTD 16v, 2.4 JTD 20v; all production periods

STEP

CHECK TO BE PERFORMED

RESOLUTION IF THE CHECK IS NOT OK

1

Turn the ignition key OFF.

Disconnect the wiring harness connector from the FAP differential pressure sensor.

Turn the ignition key ON.

Select the following system on the diagnostic equipment: Electronic diesel injection system EDC16C39. Check that error P0697 – Sensor 3 power supply is “Present”

Replace the differential pressure sensor

Op. 1080B82 PARTICULATE FILTER DIFFERENTIAL PRESSURE (D.P.F.) SENSOR - R R

2

Turn the ignition key OFF.

Disconnect the cable loom connector from the linear sensor.

See K120 LINEAR SENSOR FOR FANS

Turn the ignition key ON.

Select the following system on the diagnostic equipment: Diesel EDC16C39 electronic injection system.

Check that error P0697 – Power supply to sensors 3 is “Present”.

Replace the linear sensor

Op. 5040B20 AIR CONDITIONING LINEAR PRESSURE TRANSDUCER - R.R.

3

Turn the ignition key OFF.

Disconnect the wiring harness connector from engine control unit connector A

Turn the ignition key ON.

Check that the voltage between pin 44 of the control unit

See M010 ENGINE MANAGEMENT CONTROL UNIT

and the earth is greater than 0.3 V.

Repair or if necessary replace the electrical wiring between the FAP differential pressure sensor and the engine control unit

See E5070 FAP PARTICLE FILTER SYSTEM

4

Turn the ignition key OFF.

Check that the resistance between pin 44 of the control unit

See M010 ENGINE MANAGEMENT CONTROL UNIT

and the earth is more than 500 kOhm.

Repair or if necessary replace the electrical wiring between the FAP differential pressure sensor and the engine control unit

See E5070 FAP PARTICLE FILTER SYSTEM

5

Turn the ignition key ON.

Check that the voltage between pin 22 of the control unit

See M010 ENGINE MANAGEMENT CONTROL UNIT

and the earth is greater than 0.3 V.

Repair or if necessary replace the electrical wiring between the linear sensor and the engine control unit

See E6021 COMPRESSOR ENGAGEMENT

6

Turn the ignition key OFF.

Check that the resistance between pin 22 of the control unit

See M010 ENGINE MANAGEMENT CONTROL UNIT

and the earth is more than 500 kOhm.

Repair or if necessary replace the electrical wiring between the linear sensor and the engine control unit

See E6021 COMPRESSOR ENGAGEMENT

7

Replace the engine management control unit

Op. 1060G80 DIESEL ELECTRONIC INJECTION CONTROL UNIT - .R
