Applies to: all engines; all production periods

When the TEG is inserted in the TEG-READER the steering is not unlocked and the TEG-READER locking/unlocking motor does not allow the TEG to turn.

Applies to: all engines; all production periods

If the introduction of the TEG is not recognized, the user must use the recovery insert to mechanically enable the rotation

Applies to: all engines; all production periods
