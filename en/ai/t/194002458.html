Applies to: all engines; all production periods

The panel is installed behind the steering wheel.

Its position guarantees maximum visibility/legibility of the information for the driver in all vehicle usage conditions (day/night) without reflections, distortions or double images.

The control panel is available in Comfort version and contains:

- electronic speedometer

- electronic rev counter

- coolant temperature gauge with overheating warning light

- fuel level gauge with reserve warning light;

- warning lights

The instrument panel is a CAN node through which information is exchanged with the Body Computer and with the other electronic units.

Speedometer: its function allows the vehicle speed to be displayed on the instrument panel. This information is obtained from the ABS control unit via the Body Computer.

Rev counter: this function involves the display on the instrument panel of the engine rotation speed by means of the message sent via the CAN from the engine management control unit.

Milometer: this function includes the display and storage of the mileometer and trip counter. Mileage information is processed by the Body Computer. A button on the panel zeros the trip counter by means of a counter.

Fuel level: the Body Computer receives the signal from the sensor integrated in the pump assembly inside the fuel tank and processes it to guarantee suitable filtering/damping for the panel gauge, also managing the reserve warning light.

Engine coolant temperature: this function involves the display of the engine coolant temperature in the instrument panel and the overheating warning light coming on by means of messages sent via the CAN from the engine management control unit.

The temperature reading is always guaranteed, even in extreme operating conditions.

At every key on the engine coolant overheating warning is checked by a continuous control signal via the dedicated red warning light.

Engine oil pressure sensor: this function involves the display on the instrument panel of the engine oil pressure warning light by means of the message sent via the CAN from the engine management control unit.

Hanbrake applied: the warning light for the handbrake status is controlled by a specific switch; in addition, if a given speed level is exceeded in conjunction with this signal, a warning signal is activated:

Insufficient brake fluid level this function involves the "insufficient brake fluid level" warning light in the instrument panel coming on with the signal sent by the Body Computer via the CAN. The switch is normally closed when brake fluid level is maximum.

The ON/OFF switch is monitored only when the key is inserted and turned ON. When brake fluid level is low, the contact closes or opens to send an earth signal to the body computer.

General failure signal (check): The Body Computer contains a function that monitors a set of systems and components and turns on a warning light if a fault is detected. The following systems are monitored:

- TMPS (system fault and tyre signals)

See E7060 TYRE INFLATION PRESSURE CONTROL SYSTEM

- Inertia switch operation

See E3040 CENTRAL LOCKING

Light failure signal: The Body Computer contains a function that monitors a set of systems and components and turns on a warning light if a fault is detected.

The following systems are monitored:

- side light, number plate light, rear fog lamp, direction indicator, brake light faults

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

See E2020 DIRECTION INDICATORS / HAZARD WARNING LIGHTS

See E2021 BRAKE LIGHTS

See E2031 REAR FOG LAMPS

See E2021 BRAKE LIGHTS
