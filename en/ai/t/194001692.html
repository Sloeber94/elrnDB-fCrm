Applies to: all engines; all production periods

With the key on, the trip meter does not zero when the TRIP button on the right steering column switch unit lever is operated.

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner equipment to the diagnostic socket.

Check that there are no faults in the instrument panel

Move on to Step 2

Presence of errors

Continue following the instructions for the diagnostic equipment

2

ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check:

  • Connections between right steering column switch unit lever and instrument panel
  • Connections between right steering column switch unit lever and earth

See E4010 INSTRUMENT PANEL

Move on to Step 3

Connections defective, earth or power suply defective

Restore the correct connections, if necessary, replace the wiring.

3

STEERING COLUMN SWITCH UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the TRIP button the right steering column switch unit lever is working properly

See E4010 INSTRUMENT PANEL

Move on to Step 4

Right lever defective

Replace the steering column switch unit

Op. 5550A10 STALK UNIT ASSEMBLY - R+R

4

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

End of diagnosis
