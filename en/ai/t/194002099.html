PRELIMINARY CHECKS

All OK

Problems encountered

Operation

Check that the engine oil level is correct

Op. 0010T11 ENGINE OIL - CHECK LEVEL AND TOP UP, IF NECESSARY

Check that the air intake/vacuum circuit is working properly by carrying out the

See Test 1048OA AIR INTAKE/VACUUM CIRCUIT CHECK

Check the condition of the fuel supply circuit and make sure that it is working properly carrying out the

See Test 1040OA FUEL SUPPLY CIRCUIT CHECK

Check the operation of the low pressure supply circuit by carrying out the

See Test 1060OB CHECK ON SUPPLY LOW PRESSURE FUEL CIRCUIT

Move on to Step 1

Oil level incorrect

Restore the correct engine oil level

Op. 0010T11 ENGINE OIL - CHECK LEVEL AND TOP UP, IF NECESSARY

AMBIENT PARAMETERS CHECK

All OK

Problems encountered

Operation

Select the following control unit at the diagnostic equipment: EDC 16C39 Diesel electronic injection control unit. Check the value of the following parameters:

. Battery voltage

See Test 5530BB BATTERY VOLTAGE CHECK

. Measured air mass

See Test 1060GG MEASURED AIR MASS CHECK

. Atmospheric pressure

See Test 1060GD ATMOSPHERIC PRESSURE CHECK

. Engine coolant temperature

See Test 1060OE CHECK ON OPERATION OF COOLANT TEMPERATURE SENSOR

. Diesel temperature

See Test 1060EA DIESEL FUEL TEMPERATURE CHECK

. Engine rpm

See Test 1060GI ENGINE SPEED CHECK

Move on to Step 2

2

PREHEATING RELAY ACTIVE DIAGNOSIS

All OK

Problems encountered

Operation

Carry out the active diagnosis for the preheating relay, checking that the result is positive.

The check on the following system is only necessary if the outside temperature is below 0 °C.

Move on to Step 4

The result of the active diagnosis is negative

Move on to Step 3
