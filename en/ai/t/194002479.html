K047 MINIMUM ENGINE OIL PRESSURE WARNING LIGHT ON CONSTANTLY

Applies to: all engines; all production periods

The Engine Management Node sends the message via the C-CAN to the Body Computer which makes it available via the B-CAN to the Instrument Panel Node.

Applies to: all engines; all production periods

Any problems in the C-CAN will light up the control unit warning lights which operate on this network. The CAN information check is designed to highlight precisely this

Applies to: all engines; all production periods

1

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment and check that the following are not present at the CAN information:

  • Node(s) not active
  • Node(s) faulty
  • Node(s) with CAN error

Move on to Step 6

1.Engine Management Node not activated and/or faulty

1.Continue as described by the diagnostic equipment

2.Fault on CAN network

2.Continue as described by the diagnostic equipment

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check, using the Examiner, whether it is possible to connect with the Body Computer Node, that there are no errors and for the presence of parameters

Move on to Step 3

Presence of errors

Continue as described by the diagnostic equipment

3

ACTIVE DIAGNOSIS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the Examiner in the Instrument Panel Node ambient check that the minimum oil pressure warning light is correctly activated in Active Diagnosis

Move on to Step 4

1.The warning light does not flash

1.Replace the instrument panel

Op. 5560B10 CONTROL PANEL - R+R

2.The warning light flashes

2.Continue to step 4

4

OIL PRESSURE SENSOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check correct operation of the oil pressure sensor

Move on to Step 5

1.Pressure sensor defective

1.Replace pressure sensor

Op. 1084A40 ENGINE OIL LEVEL SENSOR - R + R

2.Oil circuit pressure not correct

2.Restore correct pressure

3.Sensor wiring defective

3.Renew the wiring

5

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner check, in the Engine Management Node, that there are no errors and that the parameters are present

Move on to Step 6

Fault persists

Replace the Engine Management Control Unit

Op. 1056B82 INJECTION/IGNITION SYSTEM E.C.U. (ONE) - R + R

5

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Using the Examiner check, in the Engine Management Node, that there are no errors and that the parameters are present

Move on to Step 6

Fault persists

Replace the Engine Management Control Unit

Op. 1060G80 DIESEL ELECTRONIC INJECTION CONTROL UNIT - .R

6

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

End of diagnosis
