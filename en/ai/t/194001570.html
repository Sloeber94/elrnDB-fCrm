Applies to: all engines; all production periods

The "CONNECT NAV+" system (integrated radio-phone-navigation system unit) P020 is supplied directly - pin 7 of connector A - from the battery via a line protected by fuse F23 of under-facia junction unit B001.

Pin 4 of connector A, integrated radio-phone-navigation system P020 is supplied with an ignition-controlled supply (INT from the steering lock control unit) via a line protected by fuse F49 of underfacia control unit B002.

Pins 1 and 3 of connector A are served by the CAN network that connects the integrated radio-phone-navigation system to the Body Computer M001 (pins 24 and 25 of connector H) and to the other system nodes. In this way, the navigation system module in the CONNECT NAV+ receives information used by the function, namely: speedometer, reverse, fuel consumption signal etc.

Pin 8 of connector A of P020 is earthed.

Steering wheel node control unit M093 supplies steering wheel control signals via the CAN network thorough the junction of clock spring D047 (pins 3 and 4).

Connection cables leave connector B, pin 2 of connector A and pin 6 of connector C of P020 for connection to HI-FI radio amplifier P070, which controls the speakers that emit the voice messages.

See E3510 RADIO

Aerial P025 containing the GPS reception device is connected to the navigation system module by means of a special coaxial cable. It also includes a cable for the radio function and a cable for the phone function (GSM).

The Cd Changer module P075 is supplied directly at pin 15 by the integrated radio-telephone-navigation system control unit P020 via which it is also operated. The follow cables lealve P020 connector E:

- pin 13: Reception serial line from the Cd changer;

- pin 14: Transmission serial line to the Cd changer;

- pin 15: Supply (+30) to the Cd changer;

- pin 16: Cd changer supply enablement;

- pin 17: Gnd for the Cd changer;

- pin 18: Cd changer audio reference;

- pin 19: Cd changer left audio;

- pin 20: Cd changer right audio;

The connection cables for the integrated radio telephone function leave connector F of P020.

See E3570 INTEGRATED RADIO PHONE
