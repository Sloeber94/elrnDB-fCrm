0010T64 BRAKE AND/OR CLUTCH FLUID CHECK LEVEL AND TOP UP AS NECESSARY

Applies to: all engines; all production periods

Check that the brake fluid in the reservoir is at the maximum level; if this is not the case, top up using the recommended fluid.

- When topping up the brake fluid, remove the reservoir cap and top up using the recommended fluid until the maximum level is reached.

Component

Type

Description

Classification

Qty.

Validity

BRAKE-CLUTCH HYDRAULIC SYSTEM

Synthetic fluid

TUTELA TOP 4FMVSS n° 116

DOT 4 - ISO 4925 - SAE J-1704 - CUNA NC 956-01

0.750 kg

The level of the fluid in the reservoir should not exceed the MAX reference.

The symbol on the tank identifies synthetic type brake fluids, distinguishing them from mineral type fluids. Using mineral type fluids damages the special braking system rubber seals irreparably.

ake great care to prevent the brake fluid, which is extremely corrosive, from coming into contact with the paintwork. If this does happen, was immediately with hot water.

Brake fluid is poisonous and highly corrosive. In the case of accidental contact, wash the parts involved immediately with neutral soap and water then rinse thoroughly. If swallowed, seek medical help immediately.
