Applies to: engines: 2.2, 1.9 JTD 8v, 1.9 JTD 16v, 2.4 JTD 20v; all production periods

The CODE unit inside Body Computer M001 is supplied by the battery (+30) by the line of maxifuse CPL B099 - pin 18 of connector F through under-dashboard control unit B002, while the ignition-operated power supply (INT from steering lock control unit) reaches pin 9 through the under-dashboard control unit B002.

The line leaving pin 29 of connector B is the W serial line connected connecting Body Computer M001 and the engine management control unit M010 through which the key recognition dialogue and exchange of codes in recovery mode takes place.

During normal operation, communcation between the Body Computer M001 and engine control unit M010 takes place via the C CAN network.

Body Computer M001 connects to instrument panel E050 via the C CAN network to manage the Passenger Compartment Protection (CODE) warning light and, if necessary, the Passenger Compartment Protection System Fault message on the panel display.

The transponder, built into the ignition (TEG Reader) H003 is connected to Body Computer M001 via the C-CAN network.

The CODE system self-diagnostic system managed by engine control unit M010 may be run by connecting to connector C pin 7 of the Body Computer.

Connector C pin 7 of Body Computer M001 receives signals from engine control unit M010 through the diagnostic line (K line) pin 25 connector A for JTD versions and pin 59 connector A for the 2.2 petrol version.
