Applies to: engines: 1.8, 2.2; all production periods; only with equipment: AUTOMATIC TRANSMISSION

CHECK TO BE PERFORMED

RESOLUTION IF THE CHECK IS NOT OK

1

Turn the ignition key OFF.

Turn off all the electrical consumers.

Reinsert fuse F18 in the engine compartment junction unit base

See B001 ENGINE COMPARTMENT JUNCTION UNIT

Turn the ignition key ON and check the fuse blows.

Move on to Step 3

A temporary current overload has occurred in the system behind fuse F18.

Move on to Step 2

2

If faults are present, repair or if necessary replace the electrical wiring for the engine compartment junction unit

See E1010 POWER SUPPLY

The test can be considered over

Replace the engine compartment junction unit

Op. 5505A13 ADDITIONAL JUNCTION UNIT IN ENGINE COMPARTMENT - R.R.

3

Disconnect the cable loom connector from the engine management control unit connector A

See M010 ENGINE MANAGEMENT CONTROL UNIT

Refit fuse F18 on the junction unit base and check that it cuts in

See B001 ENGINE COMPARTMENT JUNCTION UNIT

Replace the engine management control unit

Op. 1056B82 INJECTION/IGNITION SYSTEM E.C.U. (ONE) - R + R

4

Disconnect the connector from the cable loom for each individual ignition coil and check that fuse F18 cuts in

See A031 IGNITION MODULE

Replace the coil that does not trigger the fuse

Op. 5510C14 IGNITION COIL/S - R.R.

5

Turn the ignition key OFF.

Disconnect the connector for the cable loom from the automatic transmission control unit

See M055 AUTOMATIC TRANSMISSION CONTROL UNIT

Refit fuse F18 in the control unit base

See B001 ENGINE COMPARTMENT JUNCTION UNIT

Turn the ignition key ON and check the fuse blows

Replace the automatic transmission control unit

Op. 2135B52 ELECTRONIC AUTOMATIC TRANSMISSION ELECTRIC CIRCUIT -ECU MOUNT R R

6

Turn the ignition key OFF.

Extract fuse F2 from the junction unit base (it is the first on the left in the top row)

See B001 ENGINE COMPARTMENT JUNCTION UNIT

Refit fuse F18 in the control unit base

See B001 ENGINE COMPARTMENT JUNCTION UNIT

Turn the ignition key ON and check that it does not intervene.

Move on to Step 8

Move on to Step 7

7

If faults are present, repair or, if necessary, replace the electrical wiring between the engine management control unit, the automatic transmission control unit, the coils and the engine compartment junction unit

See E7050 AUTOMATIC TRANSMISSION

e

See E5030 PETROL ENGINES ELECTRONIC MANAGEMENT

The test can be considered over

Replace the engine compartment junction unit

Op. 5505A13 ADDITIONAL JUNCTION UNIT IN ENGINE COMPARTMENT - R.R.

8

Turn the ignition key OFF.

Refit fuse F24 in the control unit base

See B001 ENGINE COMPARTMENT JUNCTION UNIT

In the junction unit, remove relay T10 from the base (it is the second from left in the bottom row).

See B001 ENGINE COMPARTMENT JUNCTION UNIT

Refit fuse F18 in the control unit base

See B001 ENGINE COMPARTMENT JUNCTION UNIT

Turn the ignition key ON and check that it intervenes.

Replace relay T10

9

If faults are present, repair or if necessary replace the electrical wiring for the engine compartment junction unit

See E7050 AUTOMATIC TRANSMISSION

Replace fuse F24
