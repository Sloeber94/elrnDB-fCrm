STEP

CHECK TO BE PERFORMED

RESOLUTION IF THE CHECK IS NOT OK

1

Check power supply (+15)

  • Connect using the Examiner in Voltmeter mode with the positive probe at pin 1 and the negative probe earthed at pin 2 of the three-way connector for the steering angle sensor on the MPU connector plate.
  • - Turn the key to the on position and read the battery voltage of around 12 volt

Check the three-way wiring connecting the MPU control unit to the SRS sensor.

Any short between the signal line and the supply line.

Wiring circuit open

Check the connectors

If the fault persists, replace the SRS sensor

Op. 3350E20 STEERING ANGLE SENSOR - R.R.

Delete the error and carry out a key-on/key-off cycle, start the engine and steer.

If the sensor is OK, replace the MPU

Op. 4130B25 POWER STEERING PUMP ASSEMBLY R R FOR VERSIONS WITH AIR CONDITIONER

2

STEERING ANGLE SIGNAL CHECK

Connect using the Examiner in Voltmeter mode to the positive probe at pin 3 and the negative probe of the steering angle sensor connector earthed

Check that there is a PWM voltage output signal for the steering angle

Check the wiring connecting the MPU control unit to the SRS sensor.

If OK replace the SRS sensor on the steering box

If the signal is OK, replace the MPU

Op. 4130B25 POWER STEERING PUMP ASSEMBLY R R FOR VERSIONS WITH AIR CONDITIONER

If the problem still persists and the MPU control unit is not faulty, replace the steering box

Op. 4130A15 POWER STEERING BOX R R WITH FRONT SUSPENSION FRAME REMOVED

(Probable problem in the sensor rotor)
