K159 GENERAL FAILURE WARNING LIGHT ON CONSTANTLY

Applies to: all engines; all production periods

Even if none of the functions indicated to be faulty by the general fault warning light is faulty, the warning light on the control panel stays lit

Applies to: all engines; all production periods

N.B.: The functions that cause the general fault warning light to come on are as follows:

Applies to: all engines; all production periods

  • Inertia switch operation (FIS)
  • Speed limit exceeded
  • Diesel filter sensor fault (only JTD)
  • Engine oil pressure sensor failure
  • Rain sensor fault (if fitted)
  • Rain sensor fault (if fitted)
  • Dusk sensor fault (if fitted)
  • Window antipinch system fault (only for HIGH version)
  • Speedometer signal fault
  • Tyre inflation pressure monitoring failure

Applies to: all engines; all production periods

1

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Carry out the following preliminary checks in order:

  • Try to start the engine
  • set the limit speed to 30 km/h and carry out a road test at a higher speed to cause the warning light to come on and the buzzer to sound. Check the buzzer is not disabled
  • With the key ON, check the engine oil minimum pressure, water in diesel filter (if a JTD engine) and MIL warning lights perform the intial test and turn off upon start-up.
  • If the vehicle is fitted with a rain sensor, with the key ON, position the wheel on the right steering wheel stalk to intermittent and check that the windscreen wiper system runs the operation check.
  • If the vehicle is fitted with a dusk sensor, set the wheel on the left steering wheel stalk to AUTO, cover the sensor and check that the low beams come on.
  • If the vehicle is equipped with a parking sensor, engage revese and check that the buzzer sounds
  • If the vehicle is fitted with antipinch window seals, lower the front windows, place an obstacle in the way of the rising glass and operate closure. Check that the window stops and goes back down.

Move on to Step 1
