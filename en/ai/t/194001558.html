Applies to: all engines; all production periods

In the specification with integrated radio-phone-navigation system “Connect Nav+”, the phone (GSM module and SIM-CARD reader) is integral with the unit.

The system includes:

- GSM module and SIM-CARD reader integrated in the radio-phone-navigation system;

- handsfree function via the radio speakers;

- microphone located in the front courtesy light;

- external aerial.

The integated radio-telephone-navigation system is a node in the CAN network, via which it exchanges information with the Body Computer and the other electronic control units. The controls are shown on the integrated radio-telephone-navigation system display.

On versions with more accessories, the steering wheel controls are in an "8+3" key configuration: these control the radio and also allow controls to be sent for the telephone function (access the phonebook, make or reject a phone call).

A "Voice Recognition" function is also available. this takes the form of a voice recognition module that acquires commands from the microphone and interprets them before sending them to the phone unit.

The aerial mount with rod is fitted on the rear of the roof: it includes three cables (triple function aerial). One is for the radio, one is the phone cable and one is for the navigation system. To sum up, the functions included are Radio, GSM, GPS.
