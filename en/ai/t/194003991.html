Refitting

- Position the vehicle on a lift.

1. Disconnect the rapid connector for the intermediate fuel return pipe, rear fuel return pipe side.

Applies to: engines: 2.4 JTD 20v; all production periods

1. Undo the bolts (1a) and remove the front pipe protection (1b).

Applies to: engines: 2.4 JTD 20v; all production periods

1. Unscrew the bolts and remove the rear pipe protection.

2. Undo the bolts (2a) and remove the bracket (2b).

Applies to: engines: 2.4 JTD 20v; all production periods

Op. 4410D16 BRACKET (ONE) RETAINING CHASSIS TO BODY - R R

1. Disconnect the rapid connector for the intermediate fuel return pipe, front fuel return pipe side.

2. Remove the intermediate fuel return pipe after having released it from the fastenings under the body.

Applies to: engines: 2.4 JTD 20v; all production periods

Refitting

Removing

- Place the intermediate fuel return pipe in its housing and secure it to the underbody using the clips.

- Connect the rapid connector for the intermediate fuel return pipe, front fuel return pipe side.

Op. 4410D16 BRACKET (ONE) RETAINING CHASSIS TO BODY - R R

- Fit the bracket in its housing and secure it using the bolts.

- Place the rear pipe protection in its housing and secure it using the bolts.

- Place the front pipe protection in its housing and secure it using the bolts.

- Connect the rapid connector for the intermediate fuel return pipe, rear fuel return pipe side.

- Remove the vehicle from the lift.
