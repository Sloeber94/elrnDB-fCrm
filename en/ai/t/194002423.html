When the handbrake is released, the rear wheels remain locked

Applies to: all engines; all production periods

1

CHECK ON CONTROL CABLE TRAVEL

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the return travel for the control cables is free from impediments

Move on to Step 2

Control cables do not slide freely.

Restore correct operation.

If damaged, replace the cables involved

Op. 3380A30 HANDBRAKE CABLE - R+R

2

ACTIVATING LEVER BUTTON CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the activating lever release button returns freely

Move on to Step 3

Adjustment incorrect.

Release and remove the button; if necessary, replace the activating lever

Op. 3380A10 HANDBRAKE LEVER - R+R

3

CHECK FASTENING OF CABLE TO REAR BRAKE

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the cable is correctly fastened to the rear brake caliper.

End of diagnosis

Cable not correctly fastened.

Make sure that the cable is correctly fastened to the brake caliper.
