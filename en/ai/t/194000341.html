Refitting

If the diesel electronic injection system control unit is being replaced, when the refitting is complete the following operations must be carried out using the Examiner.

Only for versions with DPF, if the diesel electronic injection system control unit is being replaced, the engine oil must be changed.

- Position the vehicle on a lift.

- Make sure that the ignition key is in the OFF position, then disconnect the battery terminal (-).
